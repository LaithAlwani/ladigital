# LA Digital — Affordable websites ($49/mo) + light redesign

> Living plan doc. Update at the end of each change: check items off, note deviations.

## Direction (current)

LA Digital is the **affordable small-business tech company**: *"Professional websites without the agency price tag."* Sell affordability, not "cheap." **Omnivo AI** is a **separate brand** (AI automation) on its own domain **https://omnivoai.ca** — introduced via a "Want your website to do more?" section that links out; never merged into pricing.

Offering (admin-editable via Convex `plans`, static fallback in `lib/site-config.ts`):
- **Professional Websites — $49/mo** (hosting & maintenance included; bigger builds = custom quote). *This is the entry offer; Convex categoryId `plans`, slug `professional-website`.*
- **SEO — per page** (placeholder $29/page until confirmed; new `"per-page"` price unit).
- **Custom Software & Apps** — Mobile / Desktop / Custom Software (custom quote, `price:0`).

Design = **light, approachable, trustworthy** (re-themed from the old dark "premium agency" look), driven by the **frontend-design** skill; code quality per **react-best-practices**. Brand orange kept as the single accent. Signature = a **$49/mo price-tag** motif. On-site chat (Leo) **removed** (code retained, unmounted).

Funnel: **$49 Website → SEO → Growth → Omnivo AI → Custom Software.**
